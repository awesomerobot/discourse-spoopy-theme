# Spoopy

A dark, moonlit Halloween theme for Discourse.

- **Halloween Town palette:** midnight plum, bone, and pumpkin, with Georgia for text and IM Fell English for headings
- **Header:** a thicket of dead branches with a will-o'-wisp wandering through it
- **Gnarly lines:** hand-drawn, uneven rules and outlines in place of plain borders across topics, lists, the sidebar, chat, and the categories page
- **Gravestone composer:** an arched, three-dimensional headstone set in heaps of dirt that crumbles off it as it rises
- **Atmosphere:** bats, a peeking ghost, rolling fog, cobwebs, and a spider that drops from its web
- **Flashlight:** a pool of warm, flickering light follows the mouse pointer
- **Little touches:** jack-o'-lantern likes, a lit candle for the topic timeline handle, and a wobbling skull spinner

Every effect can be toggled in the theme settings, and all motion stops for visitors who prefer reduced motion.

## Loading splash screen


`splash/nightmare-splash.svg` is an animated splash image: bats flapping across a full moon behind a dead branch. Themes can't set it for you; upload it in **Admin → Settings → `splash_screen_image`**. It uses the colour scheme's `--primary` and `--secondary`, so it matches Halloween Town, and it holds still for visitors who prefer reduced motion.
